# AI 連携型動画納品サービス 営業・提案用実戦ガイド (社内用)

本ドキュメントは、本システムを通じて生成される構造化データ資産（`insight_spec`）の価値を顧客（EdTech、講座事業者、マーケター等）に魅力的に提案し、初回の商談獲得および成約率を最大化するための営業・提案担当者向けの支援ガイドです。

---

## 1. サービスの一言定義（エレベーターピッチ）

> **「私たちは、単なる動画ファイルや報告レポートを納品する会社ではありません。お手元の動画資産を、AIがいつでも100%理解し、質問に瞬時に答えてくれる『AI対応型・動画知能データベース』に変えてお届けします。」**

### 💡 背景にある顧客の痛み
これまでの動画納品や分析レポートは、納品された瞬間に「死蔵される資産」になりがちでした。
- 「あの動画のあの解説は、何本目の動画にあったっけ？」と毎回見返す時間がない。
- 「動画の内容を会議資料用に要約して」と部下に頼んでも、数時間から数日待たされる。
- 過去の動画知見がバラバラで、次にどのテーマで動画を作れば良いか分からない。

本サービスは、動画に「AIが直接読み込める設計図（JSON）」をセットにして納品することで、社内のすべての動画資産を**「いつでも瞬時に検索・要約・比較・再利用可能な『生きた知のライブラリ』」**にアップデートします。

---

## 2. 顧客に提供する納品パッケージ

顧客に納品するものは、動画ファイルそのもののほかに、以下の高度に構造化されたデータセットです。

1. **`insight_spec_{id}.json` 【AI活用のための最終正本】**
   - 音声認識とスライドOCRテキストをベースに、Gemini LLM が「ビジネステーマ」「難易度（初心者/中級/上級）」「購買ファネルステージ（認知/教育/クロージング等）」を高度にラベル付けしたJSONデータ。AI接続時の一次情報として最も重要なデータです。
2. **`Mk2_Sidecar_{id}.db` (SQLite) 【補助・将来の拡張土台】**
   - 知識要素とスライドテキストの対応関係を格納したリレーショナルデータベース。将来的に時間位置の精緻化や自社システム連携を行うための堅牢な土台です。
3. **`reports/executive_summary/` (HTML/Text) 【即納レポート】**
   - 経営層やクライアントにそのまま提出・報告できる、A4 1枚相当にまとめられた美しいエグゼクティブサマリー。

---

## 3. 顧客に刺さる価値（バリュープロポジション）

### ① 動画を見返さなくても、AIに聞けば知見を瞬時に引き出せる
- 過去のすべての動画データをAI（ChatGPTやGemini）に学習させることで、「〇〇のテーマについて解説している動画の主張を3つまとめて」「初心者がLPOを学ぶ際につまずきやすいポイントをリストアップして」といった対話形式の質問に、AIが1秒で答えてくれるようになります。

### ② 「単なるレポート」ではなく「再利用できる知識資産」の獲得
- PDFや紙のレポートは再利用が困難ですが、本システムは汎用性の高い「JSON形式」で構造化して納品するため、将来的に社内のデータベースに結合したり、自社のAIチャットボットに読み込ませてカスタマーサポートや社内教育に横展開することが容易です。

### ③ クライアント・経営報告のコストをゼロへ
- A4 1枚に美しくフォーマットされた「HTML版サマリー」が自動生成されるため、経営会議での報告や、クライアントへの施策報告書の作成コストがゼロになります。AIに指示して「これをそのまま提案書用スライドの原稿に変換して」と頼むことも可能です。

## 4. 営業トークにおける「強く言ってよい範囲」と「抑制すべき表現」

顧客との信頼関係を守り、ハルシネーション（嘘）のない堅牢な提案を行うため、提案時の表現には明確な線引きを設けます。

| 強く訴求してよいこと (強く言う) | 言いすぎになること / 禁止表現 (抑制する) |
| :--- | :--- |
| **動画資産の構造化とAI連携性**<br>「AIが動画の意味を完全に理解し、瞬時に回答できるデータセットとして納品されます」 | **秒単位の厳密な再生特定（現状非対応）**<br>❌「AIに聞けば、動画の何分何秒の場所にジャンプして再生できます」<br>※Sidecar DBの時間情報は現在開発中のプレースホルダー`(0,0)`のため、動画（講座）単位での特定に留める必要があります。 |
| **勝ち筋・高反応傾向の抽出**<br>「視聴者の関心を惹きつけやすいコンテンツタイプやテーマの『勝ち筋（傾向）』をAIがデータから高精度に導き出せます」 | **「バズる型」の完全自動・確定的予測**<br>❌「AIが動画のバズる型を100%完全再現し、次に作れば必ずヒットする動画を当てられます」<br>※実データにはCTRや離脱率などのミクロ指標はないため、「確実なバズの予測」ではなく「勝ち筋の仮説抽出」と言い表します。 |
| **経営者向けレポートの即時要約**<br>「データから経営層やクライアントに提出できる綺麗なサマリーが瞬時に自動出力されます」 | **完全自動での意思決定**<br>❌「AIがあなたの会社のマーケティング戦略をすべて自動で決定し、人間は何も判断しなくて良くなります」 |

## 5. よくある想定反論と切り返しトーク (FAQ)

### 反論①：「動画ファイルと、普通のテキスト起こし（SRT）だけあれば十分じゃない？」
- **切り返し**:
  > 「単なるテキスト起こしの場合、AIに『この動画の核となる主張（センターピン）を整理して』と聞いても、雑談や前置きなどの不要な情報に惑わされ、的確な回答が得られません。当社の納品データは、すでにAIが理解しやすいように『理論』『戦略』『具体例』といった単位に美しく分解され、さらに『購買ファネル（認知・教育・LTV）』や『ビジネステーマ』のラベルが完全に付与されています。この構造化があって初めて、AIは『認知フェーズに効く施策は何か？』といった実務レベルの質問に、一瞬で正確に回答できるようになります。」

### 反論②：「SQLite データベースはどうやって使えばいいの？」
- **切り返し**:
  > 「基本的には、AIチャットに直接添付して対話を行う際は、最もリッチな **`insight_spec.json` (JSONファイル)** を主契約データとしてご利用いただくことを推奨しています。AIはJSONの解釈が極めて得意です。一方、SQLite データベース（Sidecar DB）は、将来的に貴社のエンジニアチームが自社システムに動画情報を結合したり、大規模な統計集計を行ったりするための、貴社専用の『知財インフラ（拡張の土台）』として機能します。」

## 6. 商談での理想的な説明ステップ

1. **痛みの共感**:
   - 過去の動画ノウハウが死蔵され、見返すコストや報告書作成に膨大な時間がかかっている現状に共感します。
2. **納品物の再定義**:
   - 動画ファイルではなく、AI対応の「動画設計図（JSON）」をセットで納品していることを説明します。
3. **実例デモ提示**:
   - 「AIに質問例カタログ（CLIENT_AI_USECASE_PROMPTS）」を見せ、実際にAIがどのようなプロフェッショナルな回答を瞬時に返すか、具体例を示します。
4. **制約の誠実な開示**:
   - 「秒単位のジャンプ機能は次期ロードマップですが、動画単位での知見引き出しやテーマ・ファネルの網羅性チェックは今すぐ完璧に稼働します」と伝え、誠実な技術力への信頼を獲得します。
5. **将来の拡張価値提示**:
   - 納品されたデータ資産を自社のAIチャットボットや社内データベースへ将来的に流用できる「無駄にならない知財投資」であることを訴求します。
