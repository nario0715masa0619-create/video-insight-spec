# ダッシュボード デモ版トリセツ

> [!WARNING]
> **【重要】この文書はデモ用途の簡易手順書です。**
> 正式な設定・運用手順については、必ず `README.md` および `docs/ENVIRONMENT_SETUP.md` を参照してください。本ドキュメントを正式手順の代替として使用しないでください。

## 目的
本ドキュメントは、ダッシュボードの「デモ時の最短起動・最短確認」を実施するための簡易手順書です。手早くローカル環境でデモを立ち上げ、表示内容を確認するための要点をまとめています。

---

## 1. 最短起動手順

以下の手順で、依存関係の解決からダッシュボードの起動までを一気通貫で行います。

**① 依存関係インストール**
```powershell
pip install -r streamlit_app/requirements.txt
```

**② Windows での `.env` 初期作成**
```powershell
.\scripts\bootstrap_user_env.ps1
```

**③ APIキー設定場所**
AIサマリー機能を利用する場合は、自動生成された以下のファイルを開き `OPENAI_API_KEY` を設定してください。
- `%USERPROFILE%\.video-insight-spec\.env`

**④ 環境確認**
環境変数が正しく読み込まれるかを確認します。
```powershell
python scripts/check_environment.py
```

**⑤ Streamlit 起動コマンド**
ダッシュボードを起動します。
```powershell
streamlit run streamlit_app/app.py
```

---

## 2. APIキーあり / なし の違い

デモ環境において `OPENAI_API_KEY` の有無で以下の挙動の違いが生じます。

- **APIキーありの場合**:
  - `NarrativeEngine` が起動し、GPT (gpt-4o) を用いた「AIサマリー」機能が利用可能になります。
- **APIキーなし（未設定）の場合**:
  - ダッシュボード自体は**クラッシュせずに起動**します。
  - 基本的な指標や表などはすべて閲覧可能です。
  - AI機能は制限され、UI上には警告文（`⚠️ AI 分析エンジンは無効化されています` 等）が表示されます。

## 3. デモ時に見る場所

ダッシュボードは大きく2つのモードに分かれています。左のサイドバーから切り替えてデモを進めてください。

### チャンネル全体分析
- **品質診断**: チャンネル全体の純度や主要KPIサマリー
- **コンテンツ分析**: 投稿カテゴリやテーマの分布
- **改善提案**: データに基づく次のアクション
- **レポート**: チャンネル全体の数値まとめ
- **競合分析サマリー**: ビジネス領域ごとの競合比較データ

### 個別動画分析
- **基本分析**: 動画単位での視聴数、いいね、コメントなどの基本指標
- **黄金の組み合わせ**: 成功要因の分析
- **隠れた弱点**: 改善ポイント
- **心理ロードマップ**: 視聴者の心理変容
- **競争優位性**: 競合に対する強み

## 4. デモ確認の合格ライン

本デモが「正常に動作している」と判断するための最低限の確認項目です。

- [ ] チャンネル全体KPIで「総再生数 / 総いいね / 総コメント」が（0固定ではなく実データに基づき）表示される
- [ ] 個別動画分析でも、各動画の「再生数 / いいね / コメント」が表示される
- [ ] `quality_score` および `ranking_score` は **「未算出」** と表示される
- [ ] APIキー設定時は、動的に生成された「AIサマリー」が表示される

---

## 5. 補足事項

- **未算出スコアについて**: `quality_score` / `ranking_score` が「未算出」なのは、現行の納品データに該当指標が存在しないためであり、**異常ではなく仕様どおり**です。フェイク値によるごまかしは行っていません。
- **正本データについて**: ダッシュボードの各種数値は `insight_spec_*.json` を正本として直接集計しています。（旧仕様の `executive_report.json` は必須前提ではありません。）
