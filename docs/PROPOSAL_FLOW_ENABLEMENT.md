# 問い合わせ〜商談化 提案導線設計ガイド (営業用実戦集)

本ドキュメントは、LPから問い合わせ・無料解析に申し込んだ見込み顧客（リード）に対し、営業担当者がどのようにアプローチし、商談獲得率および成約率を最大化するかを設計した実践的な営業用ガイドです。

PR #22で整備された `OnePager` や `AI質問例カタログ` などのドキュメントを営業フローの適切なタイミングで活用し、「無料解析 → 価値実感 → 本商談」の流れを自然に構築します。

---

## 1. 提案導線全体のロードマップ

LPから「無料解析」や問い合わせが入った後の営業プロセスと、使用する資料のタイミングは以下の通りです。

| フェーズ | アクション | 送付・使用する資料 | 営業のゴール |
| :--- | :--- | :--- | :--- |
| **① 問い合わせ直後**<br>(即日〜24時間以内) | サンクスメールの送付と、無料解析の動画ヒアリング。 | [CLIENT_ONEPAGER_AI_DATASET.md](docs/CLIENT_ONEPAGER_AI_DATASET.md) (PDF版) | 顧客から解析対象の動画URLまたはファイルを確実に回収する。 |
| **② 動画解析中**<br>(受領から3〜5営業日) | AIバッチ解析の実行、データ生成。 | バックエンドシステム（`competitor_analytics_generator`）の自動実行 | ミスのない正確なデータおよびサマリーHTMLの作成。 |
| **③ 解析完了・納品**<br>(解析完了即日) | 解析結果（要約レポート）の送付と、結果説明のための「15分デモ商談」の打診。 | 無料解析結果サマリー (HTML/PDF版) | **15分のオンラインミーティング（Zoom/Teams）の日程を獲得する。** |
| **④ 15分デモ商談**<br>(商談当日) | 画面共有によるChatGPT実演、他社との違いの解説、本提案。 | [CLIENT_AI_USECASE_PROMPTS.md](docs/CLIENT_AI_USECASE_PROMPTS.md) (PDF版) | 自社分析プラン、または自社＋競合分析プランの「本見積り」提示・成約。 |

## 2. 営業活動用テンプレート集

> **送信タイミング**: 問い合わせまたは無料解析の申し込みから24時間以内。
> **目的**: 期待感を醸成し、解析対象動画のURLをスムーズに回収する。

```text
件名：【株式会社ルヴィラ】無料動画解析へのお申し込みありがとうございます

〇〇株式会社
役職・お名前 〇〇 〇〇 様

いつもお世話になっております。
株式会社ルヴィラの〇〇（営業担当名）と申します。

この度は、弊社の「AI対応型・動画知能データベース構築サービス」の
無料1本お試し解析にお申し込みいただき、誠にありがとうございます。

本サービスは、単なる動画の文字起こしや分析代行ではなく、
貴社の動画データを「AI（ChatGPT等）がいつでも瞬時に理解し、対話できる資産（JSON）」
にアップデートして納品するサービスです。

解析の開始にあたり、まずは対象とする動画をご指定いただきたく存じます。

--------------------------------------------------
■ 無料解析用の動画について

恐れ入りますが、以下のいずれかの方法で解析をご希望の動画をご指定ください。

1. YouTube上に公開されている動画の場合：
   対象動画のURLを本メールへの返信にてお知らせください。

2. 未公開の動画ファイルの場合：
   ギガファイル便やGoogleドライブ等の共有リンクにアップロードいただき、
   そのダウンロードURLをお知らせください。

※まずは「貴社が最も重要とされている講義動画・解説動画」を1本（30分以内推奨）
  ご指定いただくことをお勧めしております。
--------------------------------------------------

また、本メールに添付にて、本データ資産がどのようにAIと連携し、
実務にどのような成果をもたらすかを簡潔にまとめた

まずは解析対象の動画URLのご返信を、心よりお待ちしております。
何卒よろしくお願い申し上げます。

--------------------------------------------------
```

### テンプレート②：無料解析結果の納品 ＆ 15分商談の打診メール
> **送信タイミング**: 動画受領後、AIによる解析データとHTML要約レポートが完成した直後。
> **目的**: 解析結果の一部を見せて驚かせ、結果説明のための「15分デモ商談」に誘導する。

```text
件名：【解析完了】無料動画解析レポートのご送付とAI実演デモのご案内

〇〇株式会社
役職・お名前 〇〇 〇〇 様

いつもお世話になっております。
株式会社ルヴィラの〇〇でございます。

お預かりしておりました貴社の動画の解析が完了いたしましたので、
一次アウトプットとして自動生成された「エグゼクティブサマリーレポート（PDF版）」
を本メールに添付にてお届けいたします。

--------------------------------------------------
■ 無料解析レポートの注目ポイント
・動画内で話されている主要な「ビジネステーマの比率」がひと目で分かります。
・視聴者がどの購買フェーズ（認知・教育・LTV等）の心理状態のときに
  最も強く反応（エンゲージメント）したか、AIが自動抽出しています。
--------------------------------------------------

本レポートは、同時に納品される「構造化データ（JSON）」を元に
共通のシステムから自動出力されたものです。

実は、このレポート以上に強力なのが、添付の「JSONデータ」を
直接ChatGPT等のAIにドラッグ＆ドロップして投げかける「対話型AI分析」です。

例えば、AIに以下のように質問するだけで、動画を1秒も見返さずに
驚くほどプロフェッショナルな回答がその場で得られます。

「この動画で、視聴者の反応が最も良かった解説の『勝ちパターン』は何ですか？」
「この動画を元に、次回の新規動画の『タイトル案（5選）』を自動作成して」

つきましては、お送りしたデータを使って、〇〇様の目の前で
ChatGPTがどのように貴社の動画内容を理解し、一瞬で回答を導き出すか、
「15分間の画面共有オンラインデモ」をさせていただきたく存じます。

ご説明は15分で完了いたします。
以下の候補日の中で、ご都合の良い日時を2〜3つご返信いただけますでしょうか。

【デモ商談 候補日時】
・〇月〇日（〇）10:00〜12:00
・〇月〇日（〇）13:00〜15:00
・〇月〇日（〇）16:00〜18:00
※上記以外でも、〇〇様のご都合に合わせますのでお気軽にお知らせください。

AIが自社の動画を100%理解し、瞬時に答えてくれる近未来の体験を、
ぜひ画面共有にてご覧ください。

何卒よろしくお願い申し上げます。
```

## 3. 商談におけるプレゼンテーションステップ

「15分」という限られた時間の中で、顧客に高い購入体験を感じさせ、本プラン（自社全体・競合分析）への移行を決定させるための理想的な商談アジェンダです。

### 最初の5分：エグゼクティブサマリーの解説（痛みの共感とファクト提示）
- **説明の要点**:
  - 送付したPDFサマリーを画面共有で提示。
  - 「ただの文字起こしだと、ここまでのテーマ分類や購買ファネル別のエンゲージメント率は手動で何時間も集計しないと出せません。ルヴィラなら最短10日で自動生成されます」と強調。
  - 顧客の「YouTube動画の成果報告や見直しの手間に時間がかかっている」という痛みに共感する。

### 中盤の5分：ChatGPTによる実演デモ（Wow体験の提供・最重要ステップ）
- **説明の要点**:
  - 商談の場でおもむろにChatGPT（有料版推奨）を開き、無料解析で作成した `insight_spec_*.json` をドラッグ＆ドロップでアップロード。
  - 事前に用意した [CLIENT_AI_USECASE_PROMPTS.md](docs/CLIENT_AI_USECASE_PROMPTS.md) の中から、顧客が最も興味を持ちそうなプロンプト（例: 「この動画データを元に、次に新規制作すべき『動画の企画タイトル案（5選）』を提案して」）をコピペして実行。
  - **目の前でAIが顧客の動画を完全に理解した高精度な企画案を数秒で吐き出すシーンを見せ、「動画知能データベース」の価値を直感的に納得させる（Wow体験）。**

### 終盤の5分：制約の誠実な開示と本提案（信頼獲得とクロージング）
- **説明の要点**:
  - 「AI質問例カタログ」を提示し、実務で使える30の質問例があることをアピール。
  - 同時に、**「秒単位の再生位置特定は、現在プレースホルダーのため非対応で、動画単位での質問に特化しています」** と誠実に開示し、「だからこそ嘘（ハルシネーション）のない安定したAI回答が可能なのです」と技術的誠実さを伝えて信頼を強固にする。
  - 「今回は1本でしたが、チャンネル全体の動画20本や、競合チャンネルの動画も同様にAIデータベース化して比較すれば、自社の真の強みと次に狙うべきテーマが浮き彫りになります」と話し、本提案（自社＋競合分析プラン：50万円〜）を提示する。

## 4. 商談化率を劇的に上げるための細部設計

- **商談前に読んでもらうべき「資料の順番」**:
  1. サンクスメール添付: [CLIENT_ONEPAGER_AI_DATASET.md](docs/CLIENT_ONEPAGER_AI_DATASET.md) （まずは価値を言葉でシンプルに理解）
  2. 解析完了時: 無料解析の「エグゼクティブサマリーPDF」（実データの可視化で品質に驚く）
  3. 商談当日: [CLIENT_AI_USECASE_PROMPTS.md](docs/CLIENT_AI_USECASE_PROMPTS.md) （コピペで使えるプロンプトで、商談後に社内ですぐ試せるようにする）
- **リマインドの徹底**:
  無料解析レポート送付後、3日以内に日程調整の返信がない場合は、「お送りしたレポートで気になる点や、他にご指定したい動画があれば追加で解析を承ることも可能です」とリマインドメールを送り、休眠化を防ぎます。
- **デモ実行時のプロンプト事前選定**:
  顧客の動画ジャンルが「BtoBの講座」か「採用動画」か「集客メディア」かに応じて、最も輝く質問（マーケティング網羅性チェック、または新規構成企画）を営業担当が事前に1つ選定し、ChatGPTの反応を予習しておくことで、商談当日のデモを円滑に進行します。
